# Codomax Digital Solutions — AI & ML Internship
## Module 01: Introduction to AI & Python (Day 1–Day 4)

This repository contains the complete beginner-level learning material and Python practical work for Module 01.

### Learning objectives
1. Understand Artificial Intelligence (AI) and Machine Learning (ML).
2. Explain the relationship between AI, ML, and Deep Learning (DL).
3. Identify real-world applications of AI.
4. Practise Python variables, data types, operators, input/output, conditions, loops, lists, and functions.
5. Write, run, and explain beginner-friendly Python programs.

### Folder guide
| Folder | Contents |
|---|---|
| `Day-01-AI-ML-DL` | Concepts, comparison, applications, revision |
| `Day-02-Python-Basics` | Variables, data types, operators, input/output |
| `Day-03-Python-Programming` | Conditions, loops, lists, functions |
| `Day-04-Python-Practice` | Beginner programs and sample runs |
| `Learning-Notes` | Consolidated module notes |
| `Submission` | Deliverables checklist and GitHub instructions |

### Requirements
- Python 3.9 or newer
- Visual Studio Code (recommended) or another Python editor
- No external Python packages are required for these exercises.

### Run a program
Open a terminal in the repository folder and run, for example:

```bash
python Day-02-Python-Basics/01_variables.py
```

On some Windows installations, use `py` instead of `python`.

### Suggested four-day schedule
- **Day 1:** Read the AI/ML/DL notes and complete the revision questions.
- **Day 2:** Run and modify each Python basics program.
- **Day 3:** Practise conditions, loops, lists, and functions.
- **Day 4:** Run all practical programs, complete the exercises, and prepare the GitHub submission.

### Important
These are learning exercises. Read the comments, run each file yourself, try different inputs, and make sure you can explain the logic. Add your own name, screenshots, observations, and any changes you make before submitting.
