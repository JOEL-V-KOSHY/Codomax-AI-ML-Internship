# Day 1 — Introduction to AI, ML and Deep Learning

## 1. What is Artificial Intelligence?
Artificial Intelligence (AI) is a field of computer science concerned with creating computer systems that can perform tasks commonly associated with human intelligence. These tasks include understanding language, recognizing patterns, solving problems, making recommendations, and supporting decisions.

**Examples:** chatbots, voice assistants, navigation recommendations, image recognition, and fraud alerts.

## 2. What is Machine Learning?
Machine Learning (ML) is a subset of AI. It enables a computer system to learn patterns from data and use those patterns to make predictions or decisions, instead of relying only on manually written rules for every case.

**Example — spam detection:**
1. Collect examples of spam and non-spam emails.
2. Represent the emails as data.
3. Train an ML algorithm using the examples.
4. Evaluate how well it classifies emails.
5. Use the trained model to predict the category of a new email.

## 3. What is Deep Learning?
Deep Learning (DL) is a subset of ML that uses artificial neural networks with multiple layers to learn complex patterns. It is commonly used for image, audio, and language tasks.

**Examples:** speech recognition, image classification, and some facial-recognition systems.

## 4. Relationship between AI, ML and DL
- AI is the broadest field.
- ML is one approach within AI.
- DL is a family of ML methods based on multilayer neural networks.

**Relationship:** AI ⟶ ML ⟶ DL (each item to the right is a subset of the one before it).

## 5. Comparison

| Point | AI | ML | DL |
|---|---|---|---|
| Meaning | Broad field of intelligent systems | Systems learn patterns from data | ML using multilayer neural networks |
| Scope | Broadest | Part of AI | Part of ML |
| Typical methods | Rules, search, planning, learning | Statistical and algorithmic learning | Neural networks with multiple layers |
| Example | Rule-based expert system | Email spam classifier | Neural-network image classifier |

## 7. Benefits and limitations
**Benefits:** can process large datasets, automate repetitive tasks, identify patterns, and support faster decisions.

**Limitations:** results depend on data quality; systems can make mistakes or reflect bias in data; some models are difficult to interpret; privacy and security must be considered; human oversight is important.

## 8. Key terms
- **Data:** information used by a computer system.
- **Algorithm:** a sequence of steps for solving a problem.
- **Model:** a learned or designed representation used to make predictions or decisions.
- **Training:** the process of fitting a model using data.
- **Prediction:** the output produced by a model for new input.
- **Neural network:** a computing model made of connected processing units arranged in layers.

## 10. Short answers

2. **ML:** A subset of AI in which systems learn patterns from data.
3. **DL:** A subset of ML that uses neural networks with multiple layers.
